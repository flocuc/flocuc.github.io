# Florian Cucurella

Programmer · Garching, Germany

I’m a programmer at a startup in Garching, with a computer science background from the Technical University of Munich.

I like understanding how languages shape the programs we write, and how good tools make difficult systems easier to reason about.

## What I’m exploring

- **Type systems and verification:** refinement types, dependent types, and practical ways to make correctness explicit.
- **Effects and functional programming:** algebraic effects, effect handlers, and keeping state and concurrency understandable.
- **Memory-safe systems:** ownership, borrowing, and the trade-offs between safety, performance, and simplicity.
- **Language implementation:** compiler intermediate representations, incremental compilation, and WebAssembly.
